# 🛠️ ระบบออกใบรับซ่อมสินค้า (Repair Ticket System)
### C# Windows Forms Application (.NET 8.0) & SQLite Database

โปรแกรมสำหรับร้านรับซ่อมอุปกรณ์อิเล็กทรอนิกส์, คอมพิวเตอร์, โน้ตบุ๊ก, สมาร์ตโฟน และเครื่องใช้ไฟฟ้า ออกแบบให้ใช้งานง่าย ตัวหนังสือใหญ่คมชัด พร้อมระบบพิมพ์ใบรับซ่อม 2 รูปแบบ (A4 แบ่งครึ่ง และ สลิปความร้อน POS 58mm) และระบบแนะนำคำศัพท์อาการเสียอัจฉริยะสไตล์ Gboard

---

## 🌟 ฟังก์ชันและความสามารถหลัก (Key Features)

1. **ระบบฐานข้อมูล SQLite อัตโนมัติ (`repair_shop.db`):**
   - ใช้งานผ่านแพ็กเกจ `Microsoft.Data.Sqlite` (ไม่ต้องติดตั้ง Database Server ภายนอก)
   - ตรวจสอบและสร้างฐานข้อมูลพร้อม 3 ตารางหลักอัตโนมัติเมื่อเปิดโปรแกรมครั้งแรก:
     - `RepairJobs`: ข้อมูลใบรับซ่อม (เลขที่ใบงาน, วันที่, ชื่อลูกค้า, อาการเสีย)
     - `ShopSettings`: ข้อมูลร้านค้า (ชื่อร้าน, ที่อยู่/เบอร์โทร) มีข้อมูลตั้งต้นพร้อมใช้งาน
     - `WordDictionary`: คลังคำศัพท์ช่างซ่อม พร้อมระบบนับความถี่เพื่อจัดอันดับคำแนะนำ
   - ปลอดภัยจาก SQL Injection 100% ด้วย Parameterized Queries ทุกคำสั่ง

2. **หน้าจอคมชัด ตัวหนังสือขนาดใหญ่ (Minimum 16pt Font Size) พร้อมเน้นเบอร์โทรลูกค้า:**
   - กำหนดขนาดฟอนต์บนหน้าจอทุกจุด **ขั้นต่ำ 16pt** (`Segoe UI` / `Tahoma`)
   - **เพิ่มฟิลด์ "📞 เบอร์โทรลูกค้า" (`txtCustomerPhone`):** จัดวางเคียงข้างชื่อลูกค้า พร้อม**เน้นฟอนต์ 16.5pt Bold สีพิเศษ** และพื้นหลังครีมอ่อน สังเกตเห็นได้ทันที
   - สระบน/ล่างและวรรณยุกต์ไทยแสดงผลครบถ้วน ไม่ตกขอบ ไม่ซ้อนทับ
   - ตาราง `DataGridView` แถวสูง 44px อ่านง่ายจากระยะไกล มีคอลัมน์เบอร์โทรลูกค้าชัดเจน เหมาะกับหน้าจอหน้าร้านและจอสัมผัส

3. **แถบแนะนำคำศัพท์อัจฉริยะสไตล์ Gboard (Word Suggestion Bar):**
   - แถบแนวนอนใต้ช่องกรอกอาการเสีย แนะนำคำศัพท์ 3-5 คำแบบเรียลไทม์ขณะพิมพ์
   - คลิกปุ่มเพื่อแทนที่คำและ **เว้นวรรคให้อัตโนมัติ (`" "`)** เพื่อพิมพ์คำต่อไปได้อย่างลื่นไหล
   - **ระบบเรียนรู้คำศัพท์อัตโนมัติ (Self-Learning):** ทุกครั้งที่บันทึกใบงาน ระบบจะตัดคำศัพท์ใหม่ๆ เก็บเข้าคลังคำศัพท์และอัปเดตความถี่การใช้งานอัตโนมัติ

4. **ระบบการพิมพ์ 2 รูปแบบ (Dual Print Engines):**
   - **📄 กระดาษ A4 แนวตั้ง (ฟอนต์ขั้นต่ำ 16pt พร้อมเน้นจุดสำคัญ):** แบ่งครึ่งเท่ากันด้วยเส้นประแนวนอนที่ `Y = 584` ครึ่งบนระบุ `(ส่วนของร้านค้า)` และครึ่งล่างระบุ `(ส่วนของลูกค้า)` ตัวอักษรทุกจุดขนาดขั้นต่ำ **16pt** พร้อม**เน้นที่อยู่-เบอร์โทรร้าน (16pt Bold)**, **เน้นเลขที่ใบงาน (17pt Bold)**, และ**เน้นเบอร์โทรลูกค้า (17pt Bold)** พร้อมช่องลงชื่อทั้งสองฝั่ง และกรอบอาการเสียกว้างขวาง
   - **🧾 สลิปความร้อน POS 58mm (Bitmap Graphic Engine):** วาดสลิปลงบนภาพ Bitmap ความกว้าง 384 พิกเซลก่อนส่งพิมพ์ แก้ปัญหาภาษาไทย ตัวอักษรเพี้ยน สระลอย หรือเครื่องไม่มีรหัสไทยได้อย่างเด็ดขาด 100% พร้อมพิมพ์ 2 สำเนาต่อเนื่องในม้วนเดียว และระบุเบอร์โทรลูกค้าครบถ้วน

5. **ระบบค้นหาและประวัติใบงาน:**
   - ค้นหาได้แบบพิมพ์แล้วกรองทันที ทั้งจาก "เลขที่ใบงาน", "ชื่อลูกค้า" หรือ "เบอร์โทรลูกค้า"
   - ดับเบิลคลิกแถวเพื่อดึงข้อมูลขึ้นมาแก้ไข หรือกด **"🖨️ พิมพ์ใบงานซ้ำ"** ได้ทันที

6. **ระบบตั้งค่าข้อมูลร้านค้า:**
   - หน้าต่างป็อปอัปสำหรับแก้ไขชื่อร้าน ที่อยู่ และเบอร์โทรศัพท์ โดยบันทึกลงฐานข้อมูลทันที ไม่ต้องแก้ในโค้ด

### วิธีที่ 1: Build แบบ Single-File บีบอัดขนาดเล็ก (แนะนำสูงสุด ⭐⭐⭐ ขนาด ~69 MB)
สร้างไฟล์ `RepairTicket.exe` ตัวเดียวจบ โดยรวมเอา .NET Runtime และไลบรารีทั้งหมดไว้ในไฟล์เดียว **สามารถนำไปดับเบิลคลิกรันบนเครื่องคอมพิวเตอร์ Windows อื่นๆ ได้ทันที 100% โดยที่ User ไม่ต้องโหลดหรือติดตั้ง .NET / Library ใดๆ เพิ่มเติม**:
- เปิดใช้งานระบบ Single-File Bundle Compression บีบอัดโค้ดและ Native Library อัตโนมัติ
- ปลดและ Strip ข้อมูล Debug Symbols (PDB) ออกทั้งหมด

```powershell
dotnet publish -c Release -r win-x64 -o ./publish
```

* **ผลลัพธ์:** จะได้ไฟล์ `RepairTicket.exe` ขนาดประมาณ **69 MB** (จากเดิมที่ไม่ได้บีบอัด ~150 MB) อยู่ในโฟลเดอร์ `C:\gemini_code\RepairTicket\publish\`
* **การนำไปใช้งาน:** คัดลอกเฉพาะไฟล์ `RepairTicket.exe` ไปวางที่เครื่องปลายทางแล้วดับเบิลคลิกเปิดใช้งานได้ทันที

---

### วิธีที่ 2: Build แบบ Strip พิเศษขั้นสุด (Ultra-Trimmed ขนาด ~47 MB)
หากต้องการลดขนาดไฟล์ `.exe` ให้เล็กลงไปอีกระดับ โดยยังคงคุณสมบัติ **Self-Contained (ไม่ต้องลง Runtime/Lib เพิ่มเช่นกัน)**:
- ใช้เทคนิค IL Trimming ตัดโค้ดและเมธอดของ .NET BCL ส่วนที่ไม่ได้ใช้ออก
- ปิดระบบ Debugger / Event Tracing ระดับ Runtime ที่โปรแกรมออฟไลน์ไม่ได้ใช้งาน

```powershell
dotnet publish -c Release -r win-x64 -p:PublishTrimmed=true -p:TrimMode=partial -p:_SuppressWinFormsTrimError=true -p:DebuggerSupport=false -p:EventSourceSupport=false -p:HttpActivityPropagationSupport=false -o ./publish-trimmed
```

* **ผลลัพธ์:** ไฟล์ `RepairTicket.exe` ขนาดเหลือเพียง **~47 MB** ในโฟลเดอร์ `C:\gemini_code\RepairTicket\publish-trimmed\` รันได้ทันทีโดยไม่ต้องพึ่งพาไฟล์ภายนอก

## 🖨️ คำแนะนำการเชื่อมต่อและระบบจำค่าเครื่องพิมพ์อัตโนมัติ (Smart Printer Memory)

บนหน้าจอหลักของโปรแกรม มีตัวเลือก **"เครื่องพิมพ์ปลายทาง" (`cboTargetPrinter`)** พร้อม**ระบบจดจำเครื่องพิมพ์ถาวรอัตโนมัติ (Persistent Printer Preferences)** ลงในฐานข้อมูล SQLite:

1. **ระบบจดจำแยกอิสระ 2 รูปแบบ (Dual Printer Memory):**
   - **เมื่อเลือกพิมพ์ A4:** โปรแกรมจะจดจำเครื่องพิมพ์ A4 ที่เลือกไว้ (เช่น HP LaserJet หรือ Canon)
   - **เมื่อเลือกพิมพ์ สลิป POS 58mm:** โปรแกรมจะจดจำเครื่องพิมพ์สลิปที่เลือกไว้ (เช่น XP-58 หรือ POS Printer)
   - **การสลับเครื่องพิมพ์อัตโนมัติ:** เมื่อผู้ใช้เปลี่ยนรูปแบบการพิมพ์ (A4 <-> POS 58mm) ในเมนู Dropdown ระบบจะสลับชื่อเครื่องพิมพ์ปลายทางไปยังเครื่องที่เคยตั้งไว้สำหรับรูปแบบนั้นให้อัตโนมัติทันที
2. **เปิดโปรแกรมครั้งต่อไปพร้อมพิมพ์ทันที:**
   - โปรแกรมจดจำรูปแบบการพิมพ์ล่าสุด (`LastPrintFormat`) และเครื่องพิมพ์ที่เลือกไว้ล่าสุด เมื่อเปิดโปรแกรมใหม่ ไม่ต้องเสียเวลาเลือกเครื่องพิมพ์ซ้ำอีกต่อไป
3. **การทำงานร่วมกับเครื่องพิมพ์ใน Windows:**
   - **เครื่องพิมพ์เอกสาร A4 (Inkjet / Laser):** รองรับเครื่องพิมพ์ทุกรุ่นใน Windows พิมพ์ครึ่งบน/ล่างด้วยพิกัดแม่นยำ
   - **เครื่องพิมพ์สลิป POS 58mm (USB / Bluetooth):** ส่งภาพ Bitmap 384 พิกเซลไปยังหัวพิมพ์โดยตรง ตัวหนังสือภาษาไทยคมชัด 100% สระไม่ลอยและไม่เพี้ยน
